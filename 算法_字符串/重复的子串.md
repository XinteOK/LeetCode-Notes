### 方法一：移动匹配
- 灵机一动式算法
```java
class Solution{
	public boolean repeatedSubstringPattern(String s){
		String t = s + s;
		t = t.substring(1,t.length()-1);
		//PS:java中的字符串String是不可变的，如果想实现类似C++的erase的效果，可以使用StringBuilder(可变字符串)的sdeleteCharAt()
		return t.contains(s);
	}
}
```

### 方法二：KMP
Just Remeber:
- 字符串的长度 - 最长公共前后缀的长度 = 最长相同前后缀不包含的子串长度
- "最长相同前后缀不包含的子串长度"以被"字符串的长度"整除，所以说明有重复的子字符串
```java
class Solution{
	public boolean repeatedSubstringPattern(String s){
		int n = s.length();
		
		//求next数组
		//前缀表不减1的版本
		int next[] = new int[n];
		int j = 0;
		next[0] = 0;
		for(int i = 1;i < n;i++){
			while(j > 0 && s.charAt(j)!=s.charAt(i)){
				j = next[j - 1];
			}
			if(s.charAt(i) == s.charAt(j)){
				j++;
			}
			next[i] = j;
		}
		//Remeber Here
		if(next[n - 1]>0 && n%(n - next[n - 1])==0){
			return true;
		}else{
			return false;
		}
	}
}
```
