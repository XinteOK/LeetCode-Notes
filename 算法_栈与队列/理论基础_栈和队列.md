### 栈
#### 简介
- 栈，也叫堆栈（Stack），一种特殊的线性表。
- 只能在表的尾部（栈顶）插入和删除。
- 先进后出
#### 数组实现栈(不重要)

```java
public class MyStack {
	private int[] arr;
	private int top; //指向栈顶的下一个元素
	
	public MyStack(int capacity) {
		arr = new int[capacity];
		top = 0;
	}
	
	//入栈
	public void push(int val) {
		arr[top] = val;
		top++;
	}
	
	//出栈
	public int pop() {
		top--;
		return arr[top];
	}
	
	//查看栈顶
	public int peek() {
		return arr[top - 1];
	}
	
	public boolean isEmpty() {
		return top==0;
	}
}
```

#### Deque接口和ArraryDeque实现类
- **LeetCode刷题java语言使用最多的栈**
- Deque，Double Ended Que，双端队列
- ***实现类***
	1. **ArrayDeque**
	- 当栈使用
```java
Deque<Integer> stack = new ArrayDeque<>();
```
底层：可变长数组（循环数组），自动扩容
特点：不允许存null

| 方法        | 作用           |
| --------- | ------------ |
| push(e)   | 头部入栈         |
| pop()     | 头部出栈，返回元素    |
| peek()    | 查看栈顶（头部），不弹出 |
| isEmpty() | 判断是否为空       |
| size()    | 元素个数         |
### 队列

#### 简介

- 队列（Queue），一种特殊的线性表。
- 只能在表的尾部（队尾）插入，在表的头部（队首）删除。
- 先进先出 FIFO

#### Queue 接口和实现类

- **LeetCode 刷题 java 语言使用最多的队列**
- Queue，队列接口
- _**实现类**_
    1. **LinkedList**

```java
Queue<Integer> queue = new LinkedList<>();
```

底层：双向链表 特点：可以存储 null

| 方法        | 作用                 |
| --------- | ------------------ |
| offer(e)  | 队尾入队，推荐使用          |
| poll()    | 队首出队，返回元素，空返回 null |
| peek()    | 查看队首，不删除，空返回 null  |
| isEmpty() | 判断是否为空             |
| size()    | 元素个数               |

> 补充另一套方法（刷题不推荐，空时抛异常）：add ()、remove ()、element ()

#### 补充：ArrayDeque 也可以当普通队列使用

```
Queue<Integer> queue = new ArrayDeque<>();
```

底层：循环可变长数组，性能优于 LinkedList；**不允许存 null**

#### 补充：Deque 双端队列（可两端操作）

```java
Deque<Integer> deque = new ArrayDeque<>();
```

| 方法            | 作用   |
| ------------- | ---- |
| offerFirst(e) | 头部添加 |
| offerLast(e)  | 尾部添加 |
| pollFirst()   | 头部取出 |
| pollLast()    | 尾部取出 |
| peekFirst()   | 查看头部 |
| peekLast()    | 查看尾部 |
|               |      |

适用场景：单调队列（LeetCode239 滑动窗口最大值）

#### 补充：PriorityQueue 优先队列（堆，属于 Queue 的实现类）

- 不遵循先进先出，自动维持堆结构

```java
// 默认小顶堆
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
// 大顶堆
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a,b)->b-a);
```

底层：动态数组实现堆 特点：只保证堆顶是最值，内部整体无序 常用方法同 Queue：offer ()、poll ()、peek () 适用场景：TopK 问题
