### 栈简介
- 栈，也叫堆栈（Stack），一种特殊的线性表。
- 只能在表的尾部（栈顶）插入和删除。
- 操作：
	- POP出栈
	- PUSH入栈

### 数组实现栈(不重要)

```java
public class MyStack {
	private int[] arr;
	private int top; //指向栈顶的下一个元素
	
	public MyStack(int capacity) {
		arr = new int[capacity];
		top = 0;
	}
	
	//入栈
	public void push(int val) {
		arr[top] = val;
		top++;
	}
	
	//出栈
	public int pop() {
		top--;
		return arr[top];
	}
	
	//查看栈顶
	public int peek() {
		return arr[top - 1];
	}
	
	public boolean isEmpty() {
		return top==0;
	}
}
```

### Deque接口和ArraryDeque实现类
- **LeetCode刷题java语言使用最多的栈**
- Deque，Double Ended Que，双端队列
### 实现类
1.**ArraryDeque**
- 当栈使用
```java
Deque<Integer> stack = new ArraryDeque<>();
```
底层：可变长数组（循环数组），自动扩容
特点：不允许存null

| 方法      | 作用           | 异常版（抛错，推荐刷题）                 |
| ------- | ------------ | ---------------------------- |
| push(e) | 头部入栈         | 满了抛异常（ArrayDeque 几乎不会满）      |
| pop()   | 头部出栈，返回元素    | 空的时候抛 NoSuchElementException |
| peek()  | 查看栈顶（头部），不弹出 | 空返回 null                     |
