#### 思路
- 使用一个队列，将数据入列，然后第一个元素回到队尾，重复此操作直到最后一个元素即可
#### 代码
```java
class MyStack {

	Queue<Integer> queue;
	
    public MyStack() {
        queue = new LinkedList<>();
    }
    
    public void push(int x) {
    queue.offer(x);
    int size = queue.size();
    while(size-- >1)
	    queue.offer(queue.poll());
    }
    
    public int pop() {
		return queue.poll();        
    }
    
    public int top() {
        return queue.peek();
    }
    
    public boolean empty() {
	    return queue.isEmpty();
    }
}   
```
