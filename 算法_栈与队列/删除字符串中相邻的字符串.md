- LeetCode1047
### 思路
- 思路和括号匹配很像
- 利用栈存储遍历过的元素
- 每遍历一位，如果是第一位（栈为空）或者和栈顶元素不相同，就存入栈；反之则删除栈顶元素（出栈）。
- 最后，栈中剩余元素就是不重复的元素
### 代码
```java
//这里可以用字符串模拟栈，之后就可以不用转换
class Solution {
    public String removeDuplicates(String s) {
        ArrayDeque<Character> deque = new ArrayDeque<>();
        char ch;
        for(int i = 0;i < s.length();i++) {
	        ch = s.charAt(i);
	        if(deque.isEmpty() || ch != deque.peek()) {
		        deque.push(ch);
	        }else {
		        deque.pop();
	        }
	    }
	    //转换为字符串形式
	    String str = "";
	    while(!deque.isEmpty()) {
		    str = deque.pop() + str;//注意顺序 
        }
        return str;
    }
}
```
