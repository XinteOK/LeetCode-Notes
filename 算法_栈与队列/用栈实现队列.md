>LeetCode232
#### 思路
- 题目要求用栈模拟队列，队列先进先出，一个栈做不到。于是思考，再加一个栈。
- 两个栈，一个叫in一个叫out，in栈按照队列顺序入栈，然后再按照自己的出站顺序弹入out栈。此时，out栈的出栈顺序就可以和队列一致。
#### 步骤
1. 定义两个栈，in和out。
2. 模拟入栈。直接用in栈push
3. 模拟出栈。in出栈，按出栈顺序入out栈(out栈必须为空).out栈再出栈。
#### 代码
```java
 class MyQueue {
    Deque<Integer> stackIn;
    Deque<Integer> stackOut;

    public MyQueue() {
        stackIn = new ArrayDeque<>();
        stackOut = new ArrayDeque<>();
    }

    public void push(int x) {
        stackIn.push(x);
    }

    public int pop() {
        if(stackOut.isEmpty()) {
            while(!stackIn.isEmpty()) {
                stackOut.push(stackIn.pop());
            }
        }
        return stackOut.pop();
    }

    public int peek() {
        if(stackOut.isEmpty()) {
            while(!stackIn.isEmpty()) {
                stackOut.push(stackIn.pop());
            }
        }
        return stackOut.peek();
    }

    public boolean empty() {
        return stackIn.isEmpty() && stackOut.isEmpty();
    }
}
```
