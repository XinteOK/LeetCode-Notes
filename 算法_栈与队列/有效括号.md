### 思路
- 将“括号不匹配”的情况列出来，发现总共有三种情况：
	1. 多了左括号
	2. 括号不匹配
	3. 多了右括号
- 在读取左括号时，我们将与其对应的右括号入栈。
- 当读取到右括号时，将我们入栈的右括号栈尾出栈与其匹配。

#### 步骤
1. 新建一个栈，用来存放右括号
2. 遍历读取给定字符串，按照不同条件分别方式处理
- 左括号：入栈相应右括号
- 右括号，匹配则出栈，不匹配则直接返回false

```java
class Solution {
    public boolean isValid(String s) {
        Deque<Character> deque = new ArrayDeque<>();
        char ch;
        for(int i = 0; i < s.length();i++) {
	        ch = s.charAt(i);
	        //左括号的三种情况
	        if(ch == '(') {
			    deque.push(')');
	        }
	        else if(ch =='{') {
		        deque.push('}');
	        }
	        else if(ch=='[') {
		        deque.push(']');
	        }
	        else {
	        //右括号
	        
	        //1.结果1：多了右括号：此时，deque为空
	        //2.结果2：右括号不匹配
	        if(deque.isEmpty() || ch != deque.peek()) {
		        return false;
	        }else {
	        //右括号匹配
		        deque.pop();
	        }
	        }
        }
        //结果3：多了左括号
        return deque.isEmpty();
    }
}
```
