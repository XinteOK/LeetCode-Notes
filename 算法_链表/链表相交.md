### 先移动长链表，然后同步移动

```java
//该注释介绍思路

//1 计算两个链表的长度
ListNode curA = headA;
ListNode curB = headB;
int lenA = 0, lenB = 0;
while(curA!=null){
	lenA++;
	curA = curA.next;
} 
while(curB !=null){
	lenB++;
	curB = curB.next;
}
//1.5 重置指针到头部
curA = headA;
curB = headB;

//2 谁长谁先走
int diff = Math.abs(lenA - lenB);
if(lenA > lenB){
	for(int i = 0;i < diff;i++){
		curA = curA.next;
	}
} 
else{
	for(int i = 0;i < diff;i++){
		curB = curB.next;
	}
}
//3 同步往后走，找交点
while(curA != null){
	if(curA == curB){
		return curA;
	}
	curA = curA.next;
	curB = curB.next;
}
return null;
```

### 合并链表同时移动法（双指针）

```java
ListNode p1 = headA, p2 = headB;
while(p1 != p2){
	if(p1 == null)
		p1 = headB;
	else p1 = p1.next;
	
	if(p2 == null)
		p2 = headA;
	else p2 = p2.next;
}
return p1;//如果没有交点，两个p全部遍历完两个链表，p1,2就都为null了
```
