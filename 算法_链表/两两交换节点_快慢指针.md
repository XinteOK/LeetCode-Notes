- 终止条件：`cur.next != null &&cur.next.next != null`
- 交换过程
```java
cur = dummyhead;
while(cur.next != null && cur.next.next != null){
	node1 = cur.next;
	node2 = cur.next.next;
	
	cur.next = node2;
	node1.next = node2.next;
	node2.next = node1;
	
	cur = cur.next.next;//cur = node1;也可以
}
return dummyhead.next;
```
