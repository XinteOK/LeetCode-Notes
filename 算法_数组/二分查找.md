- *区间定义* 决定边界写法：左闭右闭[ringht,left],左闭右开[right,left)
1. 定义两个区间：
```java
int left;
int right;
```
2. 循环查找
```java
while(left <= right){
    int middle = (left + right)/2;
    if(target > nums[middle])
	    left = middle + 1;//两种左闭都是
	else if(target < nums[middle])
		right = middle - 1;//[,]
	    //right = middle;  //[,)
	else return middle;
}
```
