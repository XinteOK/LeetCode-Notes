## 移除元素
- 快指针：遍历元素，获取元素
- 慢指针：保留符合要求的元素---*取了元素后，移动*
```java
int slow;
for(int fast;fast<nums.length;fast++){
	if(nums[fast] != val){
	//val为要删除元素
		nums[slow] = nums[fast];
		slow++;
	}
}
return slow;//此时slow为新数组大小
```

## 有序数组的平方 No.977
- 两个指针从两边开始遍历（两边平方后一定最大）
- *符合要求的保留，且移动*
- 定义一个新数组，储存结果
```java
int l = 0; int r =nums.length - 1;
int[] result = new int[nums.length];
int k = nums.length - 1;
while(l<=r){
	if(nums[l]*nums[l] >= nums[r]*nums[r]){
		result[k] = nums[l]*nums[l];
		k--;
		l++;
	}
	else{
		result = nums[r]*nums[r];
		k--;
		r++
	}
}
return result;
```
