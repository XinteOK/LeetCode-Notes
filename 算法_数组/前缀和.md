- 通过前缀和求*区间和*公式：`sum = p[b] - p[a-1]` ，a=0的情况要特殊考虑。

## 区间和
- 求区间和的题目都可以考虑前缀和辅助。
```java
import java.util.Scanner;

public class Main {

    public static void main(String args[]) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] Array = new int[n];
        int[] Sum = new int[n];
        int sum = 0;
        for (int i = 0; i < n; i++) {
            Array[i] = sc.nextInt();
            sum += Array[i];
            Sum[i] = sum;
        }
        
    while(sc.hasNextInt()){//只要有数输入就不会停下
        int a = sc.nextInt();
        int b = sc.nextInt();
        int result;
        if(a == 0){
            result = Sum[b];
        }
        else{
            result = Sum[b] - Sum[a - 1];
        }
        System.out.println(result);
    }
        sc.close();
    }
}
```

## 开发商买土地

- 先读题：只能横“一刀”切和竖“一刀”切
- 1、输入二维数组，顺便计算总面积 2、计算每行和每列的和
- 3、通过前缀和和总面积计算差值
```java
import java.util.Scanner;

public class Main{
    public static void main(String args[]){
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        int[][] p = new int[n][m];
        int sum = 0; 
        for(int i = 0;i < n;i++){
            for(int j = 0;j < m;j++){
                p[i][j] = sc.nextInt();
                sum += p[i][j];
            }
        }

        int[] honrizontal = new int[n];
        for(int i = 0;i < n;i++){
            for(int j = 0;j < m;j++){
                honrizontal[i] += p[i][j]; 
            }
        }

        int[] vertical = new int[m];
        for(int j = 0;j < m;j++){
            for(int i = 0;i < n;i++){
                vertical[j] += p[i][j];
            }
        } 

        int result = Integer.MAX_VALUE;
        int honrizontalCut = 0;
        for(int i = 0;i < n;i++){
            honrizontalCut += honrizontal[i];
            result = Math.min(result,Math.abs((sum - honrizontalCut) - honrizontalCut)); 
        }
        int verticalCut = 0; 
        for(int j = 0;j < m;j++){
            verticalCut += vertical[j];
            result = Math.min(result,Math.abs((sum - verticalCut) - verticalCut)); 
        }

        System.out.println(result);
        sc.close();
    }       
}
```
