## 螺旋矩阵II No.59
- **模拟过程**
- 画图，决定区间为*左闭右开*
- `startx,starty`作为每一圈`loop`的起始点
- `i,j`表示行和列
- `offset`来控制随着loop增加，边长度的减少（遍历条件）
```java
int i = 0, j = 0;
int startx = 0, starty = 0;
int loop = 0;
int offset = 1;
int count = 1;
int[][] result = new int[n][n];
while(loop <= n / 2){
	for(j = 0;j < n - offset;j++){
		result[startx][j] = count++;//count++“不是”一个整体，count先赋值，再自增
		
	}//[startx]是因为每一圈的开始点不一样，所以“第一行”必须[]里面为startx
	for(i = 0;i < n - offset;i++){
		result[i][j] = count++;
	}
	for(;j > starty;j--){
		result[i][j] = count++;
	}
	for(;i > startx;i--){
		result[i][j] = count++;
	}
	loop++;
	offset++;
	startx++;
	starty++;
}
//n为奇数单独处理
if(n % 2 == 1){
	result[startx][starty] = count;
}
return result;
```
