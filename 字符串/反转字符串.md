- 双指针

```java
class Solution {
    public void reverseString(char[] s) {
        int l = 0; int r = s.length - 1;
        char temp;

        while(l < r) {
            temp = char[l];
            char[l] = char[r];
            char[r] = temp;
            l++;
            r--;
        }
    }
}
```
