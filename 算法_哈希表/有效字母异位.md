- 创建一个数组，记录两个字符串中字母出现的次数
- key记录字母，value记录次数
- 第一个字符串字母每次出现，value++;第二个则--
- 如果最后record数组中每个元素都为0，则两个字符串相同
```java

    public boolean isAnagram(String s, String t) {
        int[] record = new int[26];
        //a-z怎么变成下标0-25，每个都减一个'a'就行
        for(int i = 0;i < s.length();i++){
            record[s.charAt(i) - 'a']++;
        }
        for(int i = 0;i < t.length();i++){
            record[t.charAt(i) - 'a']--;

    }
}
```
