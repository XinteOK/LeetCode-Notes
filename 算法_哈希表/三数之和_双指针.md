### leetcode no.15


- *一个要点* `nums[i] == nums[i + 1]`和`nums[i] == nums[i - 1]`的区别，选择前者会漏掉符合要求的类似于{-1,-1,2},{0,0,0}

- *新学到的语法* ：
	- 给数组排序 `Arrays.sort()` 字符串数组也可以，必须导入`import java.util.Arrays`
	- 把数组转变为List集合 `Arrays.asList()`

- *双指针思路* ：
	1. 给所给数组排序，方便双指针移动
	2. 遍历每个数组元素，每个元素需要"去重"
		- 遍历每个元素时：right > left时，通过双指针往里移动
		- 筛选出符合条件的存入result，同时给left,right去重

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(nums);

        for(int i = 0;i < nums.length; i++){
            if(nums[i] > 0){
                return result;
            }

            if(i > 0 && nums[i] == nums[i - 1]){
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;
            while(left < right){
                int sum = nums[i] + nums[left] + nums[right];
                if(sum > 0){
                    right--;
                }
                else if(sum < 0){
                    left++;
                }
                else{
                    result.add(Arrays.asList(nums[i],nums[left],nums[right]));
                    while(right > left && nums[right] == nums[right - 1]) right--;
                    while(left > right && nums[left] == nums[left +1]) left++;

                    right--;
                    left++;
                }
            }
        }
        return result;
    }
}
```
